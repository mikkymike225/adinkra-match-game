# Adinkra Match Game

A simple playable web game for matching Ghanaian-Akan Adinkra symbols with their names and meanings.

## Matches
- DUAFE — Beauty
- OSRANE — Crescent
- NYANSAPO — Wisdom
- OWUO ATWEDEE — Mortality
- EPA — Justice
- KINTINKANTAN — Arrogance

Designed as a static site, ready for Cloudflare Pages.
